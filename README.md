МИКРОСЕРВИС ДЛЯ УПРАВЛЕНИЯ СЧЕТАМИ И ПЛАТЕЖАМИ В МИКРОСЕРВИСНОЙ АРХИТЕКТУРЕ НА SPRING BOOT 4

Billing Service — это микросервис, отвечающий за выставление счетов и обработку платежей.
Он является частью микросервисной архитектуры и взаимодействует с другими сервисами (Customer Service, Payment Service) через REST API и Kafka.

На данный момент реализованы все сущности с соответствующими им dto, интерфейсы для быстрого доступа к БД, сервис с реализованными методами для поиска и создания счетов,
мапперы вынесены в отдельные классы чтобы не засорять сервис
